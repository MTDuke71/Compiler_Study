## Session Notes

Very High level: Src Files -> **Compiler** -> Machine code (Text -> Behavior)
Compiler has 6 stages, and each phase makes the input more precise so at the end you can get down to machine code,  after starting with a human friendly programming language.
	This is known as [[ambiguity-and-phases]]

	Flow Diagram
**Text** (characters) → **Lexing** → Tokens → **Parsing** → AST (structure) → **Semantic Analysis** → Annotated AST (meaning) → **IR Translation** → IR → **Optimization** → Optimized IR → **Code Generation** → Machine Code
